# 01 — Resumo do Projeto

## Nome
**PintorPro 360** — nome provisório validado durante a conversa. Pode ser trocado depois, mas deve continuar como referência técnica.

## Objetivo principal
Criar uma plataforma digital premium para pintores autônomos e pequenas equipes de pintura. O sistema não deve ser apenas um app de orçamento; deve ser uma central inteligente para criar diagnósticos, orçamentos, propostas profissionais em PDF, mensagens para WhatsApp, acompanhamento de obra, portfólio e pós-venda.

## Promessa
> Transforme cada orçamento em uma proposta profissional que valoriza seu serviço, passa confiança ao cliente e aumenta suas chances de fechar pelo WhatsApp.

## Público-alvo
- Pintores autônomos brasileiros.
- Pequenas equipes de pintura.
- Prestadores de serviço que atendem pelo WhatsApp.
- Profissionais que querem cobrar melhor e parecer mais organizados.

## Problema resolvido
O pintor normalmente envia orçamento simples, sem diagnóstico, sem justificativa de valor e sem registro claro do combinado. Isso faz o cliente achar caro, reduz a confiança, dificulta fechamento e aumenta risco de mal-entendidos.

## Diferencial central
**Proposta Inteligente de Pintura**: documento/fluxo que une diagnóstico da superfície, orçamento, escopo, inclusos/não inclusos, justificativa de valor, prazo, garantia, validade, aceite e mensagem de WhatsApp.

## Estado atual da conversa
Foi criado um protótipo inicial em React + Vite no StackBlitz para validar fluxo e PDF. O protótipo teve tela de proposta e PDF premium em 3 páginas. Depois foi decidido migrar para uma base final em **Next.js + Supabase + Vercel + GitHub** para evitar retrabalho.

## Decisão atual
Não continuar finalizando o produto no protótipo Vite. Usar o protótipo como referência visual/funcional e construir a base real em Next.js.

## Meta final
O produto só deve ser considerado excelente quando tiver visual premium real, fluxo simples para pintor leigo, PDF profissional, dados salvos com segurança, diferenciação forte e baixo risco de parecer app genérico de orçamento.
