# 08 — Prompt para Codex

Você é um engenheiro sênior full-stack especializado em Next.js, TypeScript, Supabase, SaaS, UX/UI premium, geração de PDF e segurança.

Continue o projeto PintorPro 360 sem reiniciar do zero conceitualmente. Use este pacote como fonte de verdade.

Missão inicial:
1. Organizar uma base Next.js limpa.
2. Garantir `npm install`, `npm run dev` e `npm run build` sem erro.
3. Criar rotas: `/`, `/dashboard`, `/clientes`, `/diagnostico`, `/orcamentos`, `/proposta`, `/whatsapp`, `/obras`, `/pos-venda`.
4. Migrar a Proposta Inteligente premium para `/proposta`.
5. Separar componentes da proposta.
6. Criar botão “Gerar PDF” com `window.print()`.
7. Criar CSS `@media print` para PDF limpo.
8. Não conectar Supabase antes de estabilizar a base.
9. Não transformar o produto em app genérico de orçamento.
10. Manter foco em pintores autônomos e pequenas equipes.

Critério de aceitação:
- Build passa.
- Rotas abrem.
- Proposta premium aparece.
- PDF é gerável.
- Código modular.
- Visual não parece protótipo amador.
