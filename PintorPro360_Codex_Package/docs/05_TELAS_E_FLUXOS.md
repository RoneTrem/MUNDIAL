# 05 — Telas e Fluxos

## Telas
Landing, login/cadastro, dashboard, clientes, diagnóstico, orçamentos, proposta, WhatsApp, obras, pós-venda e portfólio.

## Fluxo principal
```txt
Cliente → Diagnóstico → Orçamento → Proposta Inteligente → PDF + WhatsApp → Aprovação → Obra → Pós-venda → Avaliação/Portfólio
```

## PDF validado
Página 1: capa, cliente, score, resumo e investimento.  
Página 2: diagnóstico, escopo, inclusos e não inclusos.  
Página 3: valorização, condições, próximos passos, validade, aprovação e rodapé.

## Navegação
Menu lateral no desktop e navegação adaptada no mobile. Rotas obrigatórias: `/`, `/dashboard`, `/clientes`, `/diagnostico`, `/orcamentos`, `/proposta`, `/whatsapp`, `/obras`, `/pos-venda`.
